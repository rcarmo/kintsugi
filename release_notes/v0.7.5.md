# Kintsugi v0.7.5

Built-in Agents now have separate **Token optimisation** and **Task oversight** controls in **Settings → Token optimizer**. Each has its own Off, Watch only and On modes. Existing settings and workspace overrides carry forward. Saving either form preserves unsaved edits in the other.

- Task oversight can suggest a different approach after repeated failures. Model-assisted oversight can use the active plan item in an existing judge call when sharing is explicitly enabled. If the plan or consent changes before sending, Kintsugi cancels the request.
- Fact proposals use recorded tool use and verification results. Timeline entries give clearer summaries of tool activity and learned facts.
- WebSocket and SSE live updates recover more reliably when you switch browser tabs.

System compatibility and policy versions are unchanged. Existing image pins and custom release sources still apply.
