# Kintsugi v0.8.12

- Fixed [#17](https://github.com/rcarmo/kintsugi/issues/17): a single slow health check no longer takes the web UI offline. System withdraws access only after three consecutive failures over at least six seconds. Installation readiness still requires a fresh successful check. System logs now record probe timing and memory-pressure context when available.
- The Plan pane renders the full Markdown in view mode. Checklist icons remain, and checkbox examples inside code blocks do not count towards progress. Edit mode still shows the original Markdown.
- Parallel background subagents can each use a different enabled model. The Subagents pane shows which model they use, and follow-up turns keep that choice. **Clear finished** moves settled subagents into a collapsed section without deleting their transcripts. They return to the main list when they get more work.

Update the whole installation to pick up the System health fix. An app-only update will not change System’s health checks.
