# Kintsugi v0.7.4

This patch improves recovery from interrupted WebSocket and SSE connections. Choose either transport in **Settings → Browser transport**. Reconnecting keeps the selected transport and preserves unsent drafts.

- Retry a stalled workspace pane without reconnecting the rest of the page. If the live connection itself fails, retry it from Settings without reloading.
- Use **Park** and **Force park** while the reconnect notice is visible. Both actions still wait for pending preview saves.
- Recover with a fresh snapshot when WebSocket writes back up. SSE discards interrupted command uploads and skips superseded visibility updates after a slow request.

System compatibility and policy versions are unchanged. Existing image pins and custom release sources still apply.
