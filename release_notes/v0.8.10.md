# Kintsugi v0.8.10

Kintsugi now uses [Earendil Pi 1.7.0](https://github.com/earendil-works/pi/releases/tag/v1.7.0), including Pi Durable. Built-in Agent accounting retains the image-output token count when the provider reports it, without adding those tokens to the output total a second time.

Pi removed its own install and update reporting. Kintsugi’s Graphite token telemetry still uses the same settings and metric paths. Image tokens remain part of `tokens.output`; there is no separate image-token metric.
