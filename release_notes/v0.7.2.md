# Kintsugi v0.7.2

## Classifier selection in Custom

- Put **Classifier / decision model** directly in Custom settings, beside the separately labelled **Text-generation model**. The default classifier is no longer buried under per-task overrides.
- Show classifier catalogue entries before their provider is connected, so GPT-6 Luna can be selected and saved with a clear **OpenAI API key required** hint.
- Distinguish API-key and OAuth credential metadata without refreshing tokens or making provider requests. OpenAI Decisions requires a direct OpenAI API key; ChatGPT/Codex sign-in does not provide access.
- Preserve the classifier choice across save/reopen without substituting a text model. Saving starts no inference, and classifier safety thresholds remain required for actions.

The optimizer remains experimental and off by default. Decisions cache-token/cost accounting is still limited by the SDK; this is tracked in [earendil-works/pi#12264](https://github.com/earendil-works/pi/issues/12264).

## Compatibility

System compatibility remains 7, the app minimum remains 0, and network/resource policy readers remain 2 and 3. Custom release sources and image pins remain authoritative.

This release includes the SQLite Agent-history conversion introduced in [v0.7.0](https://github.com/rcarmo/kintsugi/releases/tag/v0.7.0). The first open converts existing JSONL journals and retains the originals in `jsonl-backup`; large histories can take several minutes.

Publishing does not deploy or restart an installation. Real-device Safari/keyboard and real-model quality/cost acceptance remain separate checks.
