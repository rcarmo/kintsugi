# Kintsugi v0.7.7

Kintsugi now uses Earendil Pi 1.6.0. The Token Optimiser waits for tool evidence from the Agent and its subagents before choosing new learning checkpoints. Learning resumes after deferred work settles, including when the root Agent has closed. Old checkpoints that split a Code Mode call and calls interrupted by cancellation or shutdown no longer block later evidence when the journal verifies how the call ended.

## Before upgrading

Take a consistent backup of the Built-in Agent journals before applying the update. Pi Durable 1.6.0 can resume older tasks, but the previous version cannot resume tasks written in the new format. If you need to roll back the app, restore the matching pre-upgrade data backup too; restoring that backup discards later journal changes.
