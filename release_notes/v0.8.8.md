# Kintsugi v0.8.8

Kintsugi now uses [Earendil Pi 1.6.1](https://github.com/earendil-works/pi/releases/tag/v1.6.1), which includes fixes for model providers and usage reporting. The built-in agent and token optimiser use the updated Pi Durable API for parked Code Mode tools, steering submissions and journal imports.

If you are upgrading from a release before Pi 1.6.0, take a consistent backup first. Rolling back the images alone does not restore journals that the older runtime cannot resume. Restore the matching pre-upgrade journals as well.
