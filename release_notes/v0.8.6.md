# Kintsugi v0.8.6

Fixed [#16](https://github.com/rcarmo/kintsugi/issues/16), where a dropped Host connection could crash System and restart active workspaces. A failed connection now closes without taking down System. Update the whole installation to get the fix; updating the app alone does not replace System.

The Token optimizer now labels **Token optimisation** and **Task oversight** separately for workspace and Agent overrides, including saved overrides. Enabled models and the session model picker sort by provider name, then model name.

The dictation shutdown test no longer reports a failure when its child has already exited. Dictation itself is unchanged.
