# Kintsugi v0.8.2

Workspace Properties now opens with an overview and groups resource limits, storage and workspace networking separately from installation-wide settings. **Delete workspace** is at the bottom and uses the existing confirmation and checks for unsaved work.

Agents no longer have a built-in workspace deletion tool. The built-in `/land` reports what it pushed and leaves the workspace in place. People can still delete workspaces in the UI, and authorised MCP admin tooling can still request deletion.
