# Kintsugi v0.8.3

Enabled models and the Built-in Agent’s session model picker now sort alphabetically by provider name, then by model name. Your enabled models, current selection and defaults are unchanged.

## Before updating from v0.7.x

Update the whole installation to get the System fixes and disk limits. Back up your installation first if you might need to roll back. The [v0.8.0 storage](https://github.com/rcarmo/kintsugi/releases/tag/v0.8.0#before-updating) and [v0.7.7 journal](https://github.com/rcarmo/kintsugi/releases/tag/v0.7.7#before-upgrading) rollback warnings still apply.
