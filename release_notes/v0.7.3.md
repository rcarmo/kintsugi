# Kintsugi v0.7.3

## Model catalogues

- Refresh built-in model definitions from **Settings → Models** without updating Kintsugi. The action shows progress and reports timeouts or provider failures.
- Refresh GitHub Copilot’s account-specific model list even when its sign-in token is still valid. Copilot’s model policies still apply. OpenRouter refreshes its account-filtered list through Pi.
- Newly discovered models still need to be enabled. Once enabled, they appear in open Agents’ model pickers without switching the selected model or discarding drafts.

## Live connections and timelines

- Recover WebSocket and SSE connections after missed wake events and unreliable browser offline hints. Visible tabs retry with capped backoff.
- Keep the recovery deadline until the initial snapshot is applied, even if the connection is still receiving heartbeats. Discard malformed cache hints and request a fresh snapshot.
- Show the action and destination in collapsed `present` tool entries. Full arguments remain in the expanded details.

## Compatibility

System compatibility remains 7, the app minimum remains 0, and the network and resource policy readers remain 2 and 3. Custom release sources and image pins remain authoritative.

This release includes the SQLite Agent-history conversion introduced in [v0.7.0](https://github.com/rcarmo/kintsugi/releases/tag/v0.7.0). The first open converts existing JSONL journals and retains the originals in `jsonl-backup`; large histories can take several minutes.
