# Kintsugi v0.6.13

## Larger resource charts

- Give Workspace and System CPU, RAM and I/O charts the full panel width, with labels and right-aligned readings above each plot.
- Increase plot height from 28 to 32 pixels while keeping fixed row sizes and value columns, so changing readings do not shift the layout.

Managed Chromium review covered the default desktop sidebar and a 390-pixel mobile viewport. At the default sidebar width, plots grow from 81 to 257 pixels wide. Sampling, history, scales and missing-data gaps are unchanged.

## Compatibility and channels

No protocol or saved-settings changes. System compatibility remains 7, the app minimum remains 0, and network/resource policy readers remain 2 and 3. The MCP settings-v2 downgrade restriction from v0.6.9 is unchanged.

Publication advances `latest` and leaves `stable` at v0.6.12. It does not deploy or restart an installation.
