# Kintsugi v0.6.1

## Token optimizer

- Fix the model picker hiding OAuth-connected providers, including GitHub Copilot and OpenAI Codex. Settings reads stored credential metadata locally without refreshing tokens or calling providers.
- Learn facts and tool-use evidence between replies, without closing the Agent. Background checkpoints process new transcript entries, coalesce overlapping work and preserve their cursor across restart. Slow learning does not block later prompts.
- Keep learning bounded: Basic makes no extra model calls. Live Model-assisted proposals require at least three evidence-bearing checkpoints (or the configured longer cadence), a ten-minute per-session cooldown, changed digest content and the existing call/spend caps. Session end retains the original proposer cadence when no live attempt has occurred; it cannot bypass the cooldown after an attempt.
- Count each fact's confirmation and exercise at most once per logical session. Tool evidence counts the session once, adds only new prompts and reconciles at session end. Resumed, previously folded sessions can learn new evidence without another session vote.
- Keep the active Agent's fact prefix unchanged for caching. Newly learned facts remain subject to the existing promotion and injection rules.
- Recover missed run-completion events after restart and stop footer status refreshes cleanly during shutdown.

## Appearance

- Use the theme accent colour and a two-pixel height for Turbo's progress bar during navigation and form submissions, including workspace creation.

## Compatibility and verification

App-only; compatibility counters are unchanged. The optimizer remains experimental and off by default. Existing journals retain their session identity and frozen fact prefix. New live checkpoints use a separate task kind so older apps leave them waiting rather than treating them as session ends. Restore hidden tools before downgrading to an app without the optimizer's Restore controls.

Local verification passed 1,554 tests across 125 files with no failures, plus lint, TypeScript and the production client asset build. Tests cover memory, SQLite and JSONL storage, replay/reopen, resumed folded sessions, non-blocking checkpoints, session-level evidence deduplication, proposer throttling and OAuth catalogue reads with networking blocked. Real-provider cost and quality measurements remain outstanding; no net-savings claim is made.
