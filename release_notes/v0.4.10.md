# Kintsugi v0.4.10

Updates Pi to 1.5.0, improves streamed transcripts and workspace switching, and fixes blank-line rendering in Files.

## Changes

- Upgrade the coordinated Pi libraries to **1.5.0**. Builtin Agent read, write and edit use Durable's native file tools, including paged reads, image processing and explicit replay policies. Code mode writes output files through the same workspace filesystem adapter.
- Add helper range reads from a single open file and canonical-path metadata. Reads keep the opened file after a rename; cancellation ends calls even when the helper stops answering. Workspace TLS authentication, namespace isolation and unprivileged file access remain enforced.
- Stream changed Markdown blocks and workspace chrome regions separately. Only selected Agent and Work panes subscribe to their content; pane failures retain local retry controls, and Home and Settings do not wait for workspace containers.
- Defer initial layout measurements and share transcript position measurements to reduce forced layouts when panes connect or become visible.
- Fix inserted blank lines in Pierre: Enter three times, Up three times, then Enter three times now displays all seven rows immediately.
- Adapt crash-loop handling to Pi 1.5: interrupted built-in steps end with an error instead of leaving the Agent busy behind the former parked-work retry notice. Task failures continue to reach the application report handler.

## Compatibility and verification

Helper protocol additions are additive. The app supplies and refreshes the helper binary, including in older workspaces. No installation compatibility counter or runtime image pin changes in this release. Docker remains **29.9.2**, with the verified fork runtime and **Go 1.27.3** toolchain introduced in v0.4.9.

Pi 1.4→1.5 journal checks preserve completed history, instructions and request deduplication on passive reopen. Interrupted safe reads recover; unsafe edits produce an interrupted/possibly-partial result without replaying the edit. Back up persisted data before upgrading; image rollback does not restore journal writes made by a newer library.

Local verification passed **2,686 tests**, with **36 skipped** and **zero failures**, plus frozen install, lint, TypeScript and helper Go checks. One earlier terminal-stop fixture failed once; its rerun and the final complete suite passed. Tagged publication separately requires full CI and native packaged System/app boot checks.

Composer layout passed **89/89 checks across six no-inference Chrome scenarios**. Provider sends, busy/long-transcript states and physical/iOS keyboards are not qualified. The soft-keyboard script could not stage a transcript because the acceptance instance had no connected model; its iOS simulator viewer was also unavailable. A live Files check saved six newlines and displayed seven rows at nonzero height.

Kintsugi retains Host terminals, centred timestamps, credential grants and caller identity, network/DNS restrictions, explicit Review/plan boundaries, Office/CSV/TSV/Draw.io, source overrides, pins and paired rollback. The outdated-image warning stays. Upstream's new PR skill and UI assertions are excluded, as are unrelated local resource-default edits. No extra prompt-suggestion inference or automatic Review commits are introduced.
