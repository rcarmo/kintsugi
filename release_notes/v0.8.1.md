# Kintsugi v0.8.1

Fixed [#15](https://github.com/rcarmo/kintsugi/issues/15), where a brief app health failure during an installation update could leave System stopped and prevent rollback.

- The installer now gives an app that stops responding up to 60 seconds to recover. It still requires a successful health check before reporting readiness.
- Automatic and manual rollback can start a stopped System and wait for its Docker engine to validate the retained app and System images. Failed updates and failed recovery checks are recorded in private host diagnostics. Rollback restores images only; it does not restore app data.

## Before updating

Update the whole installation to get the installer, System and host updater fixes. Take a consistent backup before upgrading if you may need to return to an older version. The [v0.8.0 storage](https://github.com/rcarmo/kintsugi/releases/tag/v0.8.0#before-updating) and [v0.7.7 journal](https://github.com/rcarmo/kintsugi/releases/tag/v0.7.7#before-upgrading) rollback warnings still apply.
