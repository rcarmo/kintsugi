# Kintsugi v0.8.5

Fixed [#16](https://github.com/rcarmo/kintsugi/issues/16), where a dropped Host connection could crash System and restart active workspaces. A failed connection now closes on its own. Other Host requests and workspaces can continue.

The Token optimizer now labels **Token optimisation** and **Task oversight** separately for workspace and Agent overrides. This includes saved overrides for workspaces that aren’t running. Enabled models and the session model picker sort by provider name, then model name.

Update the whole installation to get the System crash fix. Updating the app alone does not replace System.
