# Kintsugi v0.8.4

Workspace and Agent overrides now label **Token optimisation** and **Task oversight** separately, including for workspaces that aren’t running. Each workspace control can follow its own global default. Existing settings are unchanged.

This release also includes [v0.8.3’s alphabetical model lists](https://github.com/rcarmo/kintsugi/releases/tag/v0.8.3) in Enabled models and the Built-in Agent’s session picker.
