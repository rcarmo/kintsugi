# Kintsugi v0.7.8

Fixed [#14](https://github.com/rcarmo/kintsugi/issues/14): the Built-in Agent's Token Optimiser reads checkpoint history in small pages and yields between them. Tool calls and results still pair across pages, and saved checkpoint boundaries still apply. Recovery lookups use the same small pages, and optimiser setup keeps only the details it needs from the active context.

If you're upgrading from v0.7.6 or earlier, take a consistent backup of the Built-in Agent journals first. [The v0.7.7 rollback warning](v0.7.7.md#before-upgrading) still applies.
